# 히어로 명세

- 상태: 초안 (검토 전)
- 관련 문서: [gacha.md](gacha.md)
- 표기: `(미정)`은 아직 결정하지 않은 항목, `(안)`은 임시 제안값

## 1. 목적

히어로는 게임의 중심이다. 플레이어는 히어로를 중심으로 전투를 운영하고, 새 히어로를 모으며 성장한다.

## 2. 동작 설명

- 게임 시작 시 **기본 히어로 1종**을 무료로 제공한다.
- 추가 히어로는 **가챠(뽑기)** 로 획득한다. (자세한 내용은 gacha.md)
- 게임은 히어로 **1명(1슬롯)** 으로 시작하고, 진행하면서 슬롯이 해금되어 전투에 **최대 3명(3인 스쿼드)** 까지 출전시킬 수 있다. (해금 조건은 [phase1-scope.md](phase1-scope.md) 참고)
- 개별 히어로 도감은 [hero-roster.md](hero-roster.md)(신화·전설·영웅), [hero-roster-rare.md](hero-roster-rare.md)(희귀), [hero-roster-advanced.md](hero-roster-advanced.md)(고급), [hero-roster-common.md](hero-roster-common.md)(일반)를 참고한다.
- 히어로 조작 방식 (미정: 직접 조작 / 자동 공격 + 스킬 수동 사용 / 배치만 하고 자동)

## 3. 히어로 데이터 항목

Unity에서는 ScriptableObject 하나가 히어로 1종의 데이터를 가진다.

| 항목 | 설명 | 예시 |
|---|---|---|
| id | 고유 번호 | hero_001 |
| name | 이름 | (미정) |
| rarity | 등급 | 일반 / 고급 / 희귀 / 영웅 / 전설 / 신화 |
| role | 클래스 | 탱커 / 광역 딜러 / 단일 딜러 / 서포터 |
| hp | 체력 | (미정) |
| attack | 공격력 | (미정) |
| attackSpeed | 초당 공격 횟수 | (미정) |
| range | 사거리 | (미정) |
| skill | 스킬 | 히어로당 1개 (안) |
| source | 획득 경로 | 기본 제공 / 가챠 |

### 3-1. 등급·클래스별 구성 (전체 목표 73종)

| 등급 | 수량 | 탱커 | 광역 딜러 | 단일 딜러 | 서포터 | 구성 특징 |
|---|---|---|---|---|---|---|
| 신화 | 1종 | - | 1 | - | - | 전체 맵 장악형 올라운더 (초광역 궁극기) |
| 전설 | 4종 | 1 | 1 | 1 | 1 | 4대 클래스별 종결 히어로 1명씩 완성 |
| 영웅 | 8종 | 2 | 2 | 2 | 2 | 클래스별 2종씩 (중·후반 주력 스쿼드) |
| 희귀 | 15종 | 4 | 4 | 4 | 3 | 속성·상태이상 연계 실험군 |
| 고급 | 20종 | 5 | 5 | 5 | 5 | 초반 덱 빌딩 및 성장 징검다리 |
| 일반 | 25종 | 6 | 6 | 7 | 6 | 기초 입문용 및 도감/컬렉션 채우기 |
| 합계 | 73종 | 18 | 19 | 19 | 17 | 대칭형 클래스 밸런스 |

- 기본 제공 히어로는 이 표의 어느 등급·클래스에 속하는지 (미정)
- 73종을 한 번에 만들지, 단계별로 나눠 추가할지 (미정, 열린 질문 참고)

## 4. 성장

- 레벨업: 재화로 레벨을 올려 능력치를 높인다. (미정: 최대 레벨, 소모 재화)
- 중복 획득한 히어로의 처리 (미정: 조각으로 변환 / 돌파 재료 / 재화로 환급)
- 승급: 고급 등급 히어로는 상위 등급 승급의 재료로 쓰인다. (고급 기획안 기준, 승급 규칙은 미정)

## 5. 예외 상황

- 전투 중 히어로가 쓰러졌을 때의 처리 (미정: 해당 전투에서 제외 / 일정 시간 후 부활)
- 이미 보유한 히어로를 뽑았을 때의 처리 (위 4번에서 결정)
- 출전 슬롯이 가득 찼을 때 교체 방법

## 6. 완료 조건

- [ ] 새 게임을 시작하면 기본 히어로가 지급된다.
- [ ] 히어로 데이터를 ScriptableObject로 추가할 수 있다.
- [ ] 히어로를 전투에 출전시킬 수 있다.
- [ ] 히어로가 능력치대로 공격한다.
- [ ] 히어로 레벨업이 동작하고 능력치에 반영된다.
- [ ] 가챠로 얻은 히어로가 보유 목록에 추가된다.

## 7. 범위 밖 (이번에는 하지 않음)

- 히어로 장비 시스템
- 히어로 간 시너지(속성 상성 등)
- 스킨, 꾸미기

## 8. 열린 질문

1. ~~전투에 출전하는 히어로는 몇 명인가?~~ → **1명으로 시작해 슬롯 해금으로 최대 3명** (결정)
2. 히어로를 직접 조작하는가, 자동으로 싸우는가?
3. 디펜스 요소(타워 등)와 히어로의 관계는 무엇인가? (예: 히어로가 타워를 대신한다 / 함께 쓴다)
4. 중복 히어로는 어떻게 처리하는가?
5. 73종을 처음부터 모두 만드는가, 출시 단계별로 나누는가? (아트, 스킬, 애니메이션 제작량이 크다) → 1단계 20종 안: [phase1-scope.md](phase1-scope.md)
6. 기본 제공 히어로는 어떤 등급과 클래스인가?
7. 일반 등급에서 단일 딜러만 7종인 이유가 있는가? (의도된 것인지 확인)
8. 1인 구간에서 서포터의 "스쿼드 전체", "다른 히어로" 효과는 어떻게 동작하는가? (안: "스쿼드 전체"는 자신을 포함하고, "다른 히어로" 대상 효과는 혼자일 때 효과가 없다.)
9. 1인 구간에서 탱커·딜러·서포터의 차이를 어떻게 체감시키는가?
