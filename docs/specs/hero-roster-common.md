## 2. 베이스 파츠 모듈화 계획 (2인 개발용 에셋 절약)

25종을 각각 다른 모델·스프라이트로 만들면 리소스 작업에만 수 주가 걸린다. **기본 체형 4개**만 만들고 **머리(헤어·모자), 무기, 색상(머티리얼)** 세 가지만 갈아 끼우는 구조로 해결한다.

```text
[4대 공용 베이스 바디 프리팹 (애니메이션 공유)]
  ├── 1. 근접 전사 체형 (Humanoid_Melee)    → 탱커 6종
  ├── 2. 로브 마법사 체형 (Humanoid_Robe)    → 광역 딜러 6종
  ├── 3. 날렵한 궁수 체형 (Humanoid_Ranger)  → 단일 딜러 7종
  └── 4. 소형·캐주얼 체형 (Humanoid_Small)   → 서포터 6종
```

### 기대 효과

- 2D 픽셀아트로 결정되어, 애니메이션은 베이스 바디 4종의 프레임만 그리면 된다. (대기, 공격 등)
- 무기와 머리 장식은 별도 스프라이트로 만들어 프레임마다 정해진 위치에 붙이고, 색상은 팔레트 스왑으로 바꾼다. (안, phase1-scope.md 3-2 참고)
- 원본이 말한 "종당 약 3분"은 3D 소켓 방식을 전제로 한 추정이다. 픽셀 방식에서는 프레임별 위치 데이터 작업이 추가되므로 실제 소요 시간은 직접 해봐야 알 수 있다.

## 3. 확인이 필요한 항목

1. ~~2D인가 3D인가~~ → **2D 픽셀아트로 결정.** 원본의 "Humanoid", "Bone", "머티리얼" 같은 3D 표현은 픽셀 방식에 맞게 바꿔서 읽는다. 캐릭터 해상도를 정해야 베이스 바디 제작을 시작할 수 있다.
2. **인간형이 아닌 히어로**: 나무그루터기 골렘, 바람개비 요정, 작은 마나 정령, 돌망치 오크 유망주는 인간형 체형에 맞지 않는다. 별도 체형을 만들지, 인간형으로 표현할지 정한다.
3. **나팔수 소년의 효과**: 본문은 "스쿼드 기본 이동 저항 보조", CSV는 "나팔 소리로 전방 약 타격"이라 서로 다르다. "이동 저항"이 어떤 스탯인지(기절·속박·넉백 중 무엇에 대한 저항인지)도 정의가 없다.
4. **수습 기도사의 범위**: "주변 아군"이라고 되어 있는데 다른 서포터는 "스쿼드 전체"를 쓴다. 히어로의 위치나 범위 개념이 있는지 정한다.
5. **사막 유목민 활잡이의 우선 타겟**: 본문에는 "이동 속도가 빠른 적 우선 사격"이라고 되어 있지만 CSV에는 없다. 타겟 우선순위를 데이터 필드로 둘지 정한다.
6. **서포터 효과 데이터 구조**: 서포터 6종은 SkillName이 None인데 실제로는 버프 효과가 있다. 데이터에 버프 종류와 수치를 넣을 필드가 필요하다.
7. **고급 장궁병과의 사거리**: 고급 장궁병은 "일반 궁수보다 1.0 길다"고 했는데, 일반 수습 궁수는 4.8, 고급 장궁병은 6.0이라 차이가 1.2다. 기준이 되는 값을 하나로 맞춘다.
8. **탄속 등 새 스탯**: 마나 정령의 "탄속"처럼 다른 문서에 없는 스탯이 있다. 전투에서 사용하는 스탯 목록을 정리한다.
9. **수치는 모두 초안**: 실제 밸런스 단계에서 확정한다.
